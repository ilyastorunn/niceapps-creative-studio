# Contributing

Thanks for helping improve Niceapps Creative Studio.

## Good contributions

- reviewed screenshot annotations with clear visual evidence;
- retrieval and critique evaluation cases that expose a real failure;
- fixes to MCP tools, schemas, installation, or cross-platform behavior;
- documentation that makes the product boundary clearer.

Image generators, universal design templates, and unsupported conversion claims are outside the first-version scope.

## Development

```bash
npm install
npm test
npm run eval:retrieval
npm pack --dry-run
```

Keep pull requests focused. Add or update tests for behavior changes and explain the product evidence behind annotation changes. Never include private app material, credentials, or copyrighted assets that you do not have permission to redistribute.

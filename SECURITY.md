# Security policy

Please do not open a public issue for a vulnerability.

Use GitHub's private vulnerability reporting for this repository. Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do not include live credentials or third-party private data.

The server reads public catalog/App Store data and accepts explicit local paths for bounded analysis and QA operations. Reports involving path traversal, unintended writes, arbitrary remote fetching, dependency compromise, or sensitive-data exposure are especially useful.
